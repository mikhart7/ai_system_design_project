# AI_USAGE — честный лог использования AI

Работа велась в паре с Claude (Claude Code). По этапам:

- **Понимание задачи**: AI предложил допущения о домене (категории, что можно автоматизировать) на основе намеренно короткого брифа кейса — не проверялись на реальных данных/стейкхолдерах (см. `SELF_REVIEW.md`). Кандидат дважды останавливал AI от перехода к планированию, пока не передал полный контекст.
- **Архитектура**: первая версия плана была рассчитана на "продакшн" стек (FAISS/Chroma, отдельная очередь). Кандидат отклонил это — задача учебная, минимальная. AI пересобрал план на дешёвый стек (TF-IDF, in-memory, sync).
- **ML/LLM-подход**: AI выбрал TF-IDF + cosine similarity вместо embeddings, чтобы не тянуть внешние модели в тайм-боксе; LLM — только для генерации текста ответа, не для классификации/решений.
- **Разработка PoC**: код написан AI по согласованному техническому плану, кандидат проверял результат по ходу.
- **Тесты и документация**: тесты написаны под реальную логику router.py, прогнаны (5/5 passed). Документация — с реальными цифрами из прогона на eval-датасете, не абстракциями.
- **Риски/edge cases**: AI сам указал ограничения своих решений (regex обходится перефразированием, нет порога уверенности для retrieval) — не только сильные стороны.

## Ошибки AI (найдены и исправлены по ходу)

1. **Порог уверенности 0.35 выбран "на глаз".** Прогон на eval-датасете показал: обе реальные ошибки классификации (confidence 0.37 и 0.45) были выше порога — ушли бы в неверный автоответ. Исправлено: порог поднят до 0.5 (коммит `fix: raise confidence threshold...`).
2. **Нерабочий импорт в первой версии `scripts/demo.py`.** Скрипт импортировал пакет `app` напрямую — при запуске `python scripts/demo.py` из корня это упало бы (sys.path берёт каталог скрипта, не корень репо). Замечено до запуска, скрипт переписан на вызовы через HTTP API.
3. **Артефакт кодировки в FAQ-файле.** В `data/faq/technical_bug_known_issue.md` при генерации попал посторонний символ в середину предложения. Замечено при повторном чтении, исправлено до коммита.
