# Риски и эксплуатация

## Highload и надёжность
- Быстрый путь (guard + classifier) синхронный и дешёвый — не зависит от скорости LLM.
- Медленный путь (RAG + генерация) в PoC вызывается синхронно для простоты; в проде должен уйти в очередь, иначе медленный LLM тормозит весь поток.
- Если LLM недоступен — тикет не зависает: либо заготовленный ответ, либо эскалация.
- Повторный запрос с тем же `ticket_id` не создаёт дубликат (идемпотентность) — нужно для retries без ошибок.

## Privacy, safety и risk
- Если в тексте есть PII (email, телефон, номер карты) — тикет сразу уходит оператору, а не в LLM.
- Денежные и security-категории (`billing_refund`, `account_access`, `abuse_or_complaint`) никогда не закрываются автоматически.
- Защита от prompt injection — только список известных фраз, обходится перефразированием. Это первый рубеж, не полноценная защита.
- Каждое автоматическое решение (категория, уверенность, причина) пишется в лог — это база для аудита.
